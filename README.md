# 追分记分

手机端台球追分记分 Web 应用：2/3 人追分、中八抢局、犯规与让杆、大金/小金/黄金九/普胜、接清/炸清、多端实时同步、多场并行、历史与技术统计。数据存在本地 SQLite。

## 开发

```bash
npm install
npm test
npm run dev
```

打开 `http://127.0.0.1:5173`。把网址发给其他手机即可一起记同一场（同一短码）。

生产构建后只跑后端也能用：

```bash
npm run build
npm start
```

默认端口 `3000`。数据目录 `./data/zf.db`，可用环境变量 `DATA_DIR` 或 `DB_PATH` 覆盖。

管理员账号密码写在项目根目录的 `config.json`（可先复制 `config.example.json`）。删除历史场次时需要输入该账号密码。也可用环境变量 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 或 `CONFIG_PATH` 覆盖。

Ubuntu 24.04 部署见 [deploy/README.md](deploy/README.md)。

## 记分规则（默认 1-4-7-10，开局可改分值）

北方常见四球追分固定分：

- 座位上 / 中 / 下固定不变。大杆、二杆、三杆标记追分顺序：普胜赢上家（大杆的上家是三杆）。
- 小局赢后赢家开下一局（大杆），上局输家变成二杆。
- 犯规 1 分：本家赔上家，下家上手（让杆犯规则赔让杆方）
- 普胜 4 分：赢上家
- 小金 7 分：赢上家
- 黄金九 4 分：三人时其余两家各赔 4；两人时对手赔 4
- 大金 10 分：三人时其余两家各赔 10；两人时对手赔 10
- 让杆：点让杆的人；打完后该胜型双倍由让杆方赔（普胜即 8 分）

## 中八（抢局）

双人中式八球：开局选择抢几局（默认 7）。普胜、接清、炸清各计 1 局，先到设定局数获胜。胜者开下一局。
